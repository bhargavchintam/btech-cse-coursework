# Types of Data Analytics

Four types of analytics, in increasing order of value and complexity (imp).

## 1. Descriptive analytics
- **What happened?**
- Summarizes past data - reports, dashboards, KPIs.
- Uses aggregation, counts, averages.
- e.g. total sales last month.

## 2. Diagnostic analytics
- **Why did it happen?**
- Finds the cause / reason behind a result.
- Drill-down, data mining, correlation.
- e.g. why did sales drop in region X.

## 3. Predictive analytics
- **What will happen?**
- Forecasts future outcomes using statistics + machine learning.
- e.g. predict next month's sales, customer churn.

## 4. Prescriptive analytics
- **What should we do?**
- Suggests the best action to take.
- Uses optimization + simulation.
- e.g. recommend the best price / route.

## Comparison
| Type | Question | Complexity | Value |
|------|----------|-----------|-------|
| Descriptive | what happened | low | low |
| Diagnostic | why it happened | medium | medium |
| Predictive | what will happen | high | high |
| Prescriptive | what to do | highest | highest |

## Note
- Order to remember: **Descriptive -> Diagnostic -> Predictive -> Prescriptive**.
- Descriptive + diagnostic look at the **past**; predictive + prescriptive look at the **future**.
