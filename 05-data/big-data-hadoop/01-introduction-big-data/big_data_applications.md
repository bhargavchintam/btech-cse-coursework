# Applications of Big Data

Big Data is used across many domains (list any 5 / explain with example).

## Domains
- **Healthcare** - patient records, disease prediction, drug research, genomics.
- **Banking / Finance** - fraud detection, risk analysis, credit scoring, algo trading.
- **Retail / E-commerce** - recommendation engines, market basket analysis, targeted ads. e.g. Amazon "customers also bought".
- **Social media** - sentiment analysis, trend detection, friend suggestions.
- **Telecom** - call data record (CDR) analysis, network optimization, churn prediction.
- **Transportation** - route optimization, traffic prediction, fleet tracking.
- **Manufacturing** - predictive maintenance, quality control, supply chain.
- **Government** - smart cities, census, crime analysis, tax fraud.
- **Education** - learning analytics, personalized learning.
- **Entertainment** - Netflix / YouTube recommendations based on watch history.
