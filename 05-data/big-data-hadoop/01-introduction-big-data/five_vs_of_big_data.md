# The 5 V's of Big Data

The characteristics of Big Data are described by the **5 V's** (imp - asked prev year).

## 1. Volume
- The **amount** of data. Main characteristic.
- Generated from social media, sensors, transactions, logs etc.
- Measured in TB, PB, EB.

## 2. Velocity
- The **speed** at which data is generated and must be processed.
- e.g. stock market ticks, sensor streams, tweets per second.
- Batch vs real-time / streaming.

## 3. Variety
- The **different types / formats** of data.
- Structured (tables), semi-structured (XML, JSON), unstructured (video, images, text).

## 4. Veracity
- The **trustworthiness / quality** of the data.
- Data may be incomplete, noisy, inconsistent or have missing values.
- Dirty data -> wrong analysis, so cleaning is needed.

## 5. Value
- The **usefulness** we can extract from the data.
- Raw data is of no use unless it gives insights for decisions.
- Turning data into business value is the final goal.

## Summary table
| V | Meaning | Example |
|---|---------|---------|
| Volume | how much data | PB of logs |
| Velocity | how fast | live sensor stream |
| Variety | how many forms | text + video + tables |
| Veracity | how trustworthy | noisy / missing data |
| Value | how useful | insight for business |

> Some texts mention only **3 V's** (Volume, Velocity, Variety - the original by Doug Laney, 2001). Veracity and Value were added later.
