# Sources of Big Data

Big Data comes from many sources, broadly grouped as below.

## Main sources
- **Social media** - Facebook, Twitter, YouTube, Instagram (posts, likes, comments, videos).
- **Sensors / IoT** - temperature, GPS, smart meters, wearables, RFID tags.
- **Transactional data** - bank transactions, online purchases, POS billing.
- **Machine / log data** - web server logs, application logs, clickstream.
- **Mobile data** - call records (CDR), app usage, location.
- **Web** - search queries, web pages, cookies.
- **Enterprise data** - CRM, ERP, emails.
- **Scientific data** - genomics, weather, astronomy.

## By who generates it
| Type | Generated by | Example |
|------|-------------|---------|
| Human generated | people | tweets, photos, emails |
| Machine generated | devices / systems | sensor readings, logs, GPS |
| Business / process | organizations | transactions, invoices |

## Points to note
- Machine-generated data grows fastest (IoT).
- Most of this data is **unstructured** (approx 80%).
- Data may be internal (company owned) or external (public, social).
