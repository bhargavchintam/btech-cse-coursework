# History of Hadoop

Hadoop was created by **Doug Cutting** and **Mike Cafarella** (imp - asked prev year).

## Origin
- Started from the **Nutch** project - an open-source web search engine (crawler + indexer).
- Nutch faced problems storing and processing billions of web pages.
- Inspiration came from two **Google research papers**:
  - **GFS (Google File System)** - published **2003** - idea for distributed storage.
  - **MapReduce** - published **2004** - idea for distributed processing.
- Doug Cutting implemented these ideas -> the storage + processing part was split out of Nutch and named **Hadoop**.

## The name
- Named after the **yellow toy elephant** of Doug Cutting's son.
- The elephant is the Hadoop logo.

## Timeline
| Year | Event |
|------|-------|
| 2003 | Google GFS paper |
| 2004 | Google MapReduce paper |
| 2005 | Hadoop created (part of Nutch) by Doug Cutting |
| 2006 | Doug Cutting joins Yahoo; Hadoop becomes separate project |
| 2008 | Hadoop becomes a top-level **Apache** project |
| 2008 | Yahoo runs a 10,000-core Hadoop cluster |
| 2011 | Hadoop 1.0 released |
| 2012 | Hadoop 2.x - YARN introduced |
| 2017 | Hadoop 3.x released |

## Points
- Google gave the **ideas** (papers); Apache Hadoop is the **open-source implementation**.
- GFS -> became **HDFS**; Google MapReduce -> became Hadoop **MapReduce**.
