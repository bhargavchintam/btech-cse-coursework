# Cloud use cases

Where cloud is actually used. Good for a "give real-world applications of cloud computing" question.

## Common use cases
- **Web / mobile app hosting** — host sites and app backends, scale on traffic. e.g. Netflix runs on AWS.
- **Storage & backup** — store files, backups off-site. e.g. Dropbox, Google Drive.
- **Big data & analytics** — process large datasets on rented clusters. e.g. BigQuery, EMR.
- **Disaster recovery (DR)** — keep a replica in cloud, fail over when primary dies.
- **Dev / test environments** — spin up temp envs, tear down after — no permanent hardware.
- **Software delivery (SaaS)** — deliver apps over browser. e.g. Gmail, Office 365, Salesforce.
- **Email & collaboration** — hosted email, shared docs, calendars.
- **IoT** — collect + process sensor data at scale.
- **Machine learning / AI** — train models on GPUs rented by the hour.
- **Content delivery (CDN)** — cache content close to users. e.g. CloudFront.
- **E-commerce** — handle festival/sale-day spikes with elasticity.
- **Gaming** — game servers, matchmaking, streaming.

## Grouped by who uses it

| Sector | How cloud is used |
|--------|-------------------|
| Startups | avoid capex, launch fast, scale later |
| Enterprise | migrate legacy apps, hybrid setups, DR |
| Education | online classes, labs, storage (e.g. LMS) |
| Healthcare | patient records, imaging storage (with compliance) |
| Banking / finance | analytics, private cloud for sensitive data |
| Media | streaming, transcoding, CDN |

## One classic example to remember
**Netflix** — moved from own datacenters to AWS; uses EC2 for streaming, S3 for storage, scales with viewer load. Standard example examiners like.
