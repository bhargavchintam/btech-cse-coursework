# Advantages and disadvantages of cloud

Standard "write any five advantages and any five disadvantages" type question.

## Advantages
- **Low cost / no capex** — no buying servers upfront, pay-as-you-go (opex not capex).
- **Scalability & elasticity** — scale up/down with demand, no over-provisioning.
- **Accessibility** — access from anywhere over network, any device.
- **Reliability & availability** — provider has redundancy, backups, multiple datacenters.
- **Automatic updates** — provider patches the infra/software.
- **Disaster recovery** — data replicated, easier backup/restore.
- **Quick deployment** — provision in minutes vs weeks for physical.
- **Focus on business** — org needn't manage hardware, focus on core work.
- **Collaboration** — shared docs/apps, many users at once.

## Disadvantages
- **Needs internet** — no connectivity → no access. Downtime hurts.
- **Security & privacy** — data sits on third-party infra, trust issues.
- **Less control** — provider owns the infra, limited low-level control.
- **Vendor lock-in** — hard to migrate between providers (different APIs, formats).
- **Data location / compliance** — data may reside in another country, legal issues.
- **Recurring cost** — over long term pay-per-use can exceed owning.
- **Limited customisation** — esp. SaaS, take what provider gives.
- **Downtime risk** — even big providers have outages (single point for the org).
