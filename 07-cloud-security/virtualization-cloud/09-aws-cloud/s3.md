# S3 - Simple Storage Service

**Definition:** S3 is an object storage service for storing and retrieving any amount of data over HTTP/HTTPS. Data stored as **objects** inside **buckets**.

- Object storage (not block, not file). Good for images, backups, static websites, logs.
- Virtually unlimited storage, 11 9's (99.999999999%) durability.

## Bucket and object
- **Bucket** - top level container. Name must be **globally unique** across all AWS. Tied to a region.
- **Object** - the file + metadata. Identified by a **key** (the name/path). Max object size 5 TB.
- **Key** - full path within bucket, e.g. `images/2020/logo.png`.

S3 has a flat structure - "folders" are just key prefixes, not real directories.

## Storage classes (imp)
| Class | Use |
|-------|-----|
| S3 Standard | frequent access, default |
| S3 Standard-IA | infrequent access, cheaper storage, retrieval fee |
| S3 One Zone-IA | IA but single AZ |
| S3 Glacier | archival, retrieval in minutes-hours |
| S3 Glacier Deep Archive | cheapest, retrieval ~12 hrs |

## Consistency (2020)
- New PUTs of new objects - **read-after-write** consistency.
- Overwrite PUTs and DELETEs - eventual consistency.

## Access control
- Buckets and objects **private by default**.
- **Bucket policy** - JSON policy at bucket level.
- **ACL** - legacy object/bucket level permissions.
- **Block Public Access** - account/bucket setting to prevent accidental public exposure.

## Features
- **Versioning** - keep multiple versions of an object, protects against accidental delete/overwrite.
- **Lifecycle rules** - auto transition objects to cheaper class or expire after N days.
- **Static website hosting** - serve a static site directly from a bucket.
- **Encryption** - SSE-S3, SSE-KMS server side; can also do client side.

## Common CLI
```
aws s3 mb s3://my-bucket          # make bucket
aws s3 cp file.txt s3://my-bucket # upload
aws s3 ls s3://my-bucket          # list
aws s3 rm s3://my-bucket/file.txt # delete
```

## EBS vs S3 (asked prev year)
| EBS | S3 |
|-----|----|
| block storage | object storage |
| attached to one EC2 (AZ scoped) | accessed over HTTP, region scoped |
| like a hard disk | like a file drop / key-value store |
