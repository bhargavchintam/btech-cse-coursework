# What is Cloud Computing

**Definition:** Cloud computing = **delivery of computing services** (servers, storage, databases, networking, software) **over the internet** ("the cloud"), on a **pay-as-you-use** basis, instead of owning physical infra.

- You rent, you don't buy.
- Resources sit in provider's data centre, you access over the network.
- Provider examples: **AWS, Microsoft Azure, Google Cloud (GCP)**.

## NIST 5 essential characteristics (imp — asked prev year)
1. **On-demand self-service** — user provisions compute/storage himself, no human at provider side.
2. **Broad network access** — reachable over network from laptop, mobile, thin client.
3. **Resource pooling** — provider's resources pooled, shared among many tenants (multi-tenant model).
4. **Rapid elasticity** — scale out/in quickly, looks infinite to the user.
5. **Measured service** — usage metered → pay only for what you use.

## Service models (3) — one-line each
- **IaaS** — rent raw infra (VMs, storage). e.g. EC2, S3.
- **PaaS** — rent a platform to build/deploy apps. e.g. Elastic Beanstalk, App Engine.
- **SaaS** — rent ready software over browser. e.g. Gmail, Office 365.

## Deployment models (4)
- **Public cloud** — owned by provider, shared by public. (AWS, Azure)
- **Private cloud** — dedicated to one org, more control + security.
- **Hybrid cloud** — mix of public + private, workload moves between.
- **Community cloud** — shared by group of orgs with common concern.

## Cloud vs traditional
- Traditional → buy servers, capital expense (CapEx), maintain yourself, slow to scale.
- Cloud → rent, operating expense (OpEx), provider maintains, scale in minutes.

## One-line definitions to memorize
- **Cloud** = on-demand IT over internet, metered, elastic.
- **Tenant** = one customer sharing the pooled infra.
