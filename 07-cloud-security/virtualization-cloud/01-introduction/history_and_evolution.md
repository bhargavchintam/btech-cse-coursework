# History and Evolution

Rough timeline of how we reached cloud computing. Read as a flow — each idea feeds the next.

## Timeline (imp)
- **1950s-60s — Mainframes & time-sharing.** Big costly machines, many users share one via terminals. First idea of "sharing one computer's power".
- **1961 — John McCarthy** proposed computing may one day be sold as a **utility** (like water/electricity). Early cloud vision.
- **1972 — IBM VM/370.** Real hardware virtualization on mainframe — many virtual machines on one system.
- **1990s — Virtual Private Networks (VPN)** by telecom → "cloud" symbol used for the shared network.
- **1999 — Salesforce.com** delivers business apps over website → early **SaaS**.
- **2002 — Amazon Web Services** launched (initially internal, then public tools).
- **2006 — AWS EC2 + S3.** Landmark. Rent virtual servers + storage by the hour → modern public cloud begins.
- **2008 — Google App Engine** → **PaaS**. Microsoft announces **Azure** (GA 2010).
- **2010s — Containers & orchestration.** Docker (2013) makes containers mainstream; Kubernetes (2014, by Google) for managing them.
- **2010s onward** — serverless (AWS Lambda 2014), hybrid/multi-cloud become normal.

## Enabling technologies (why cloud became possible)
- **Virtualization** — split one server into many, the core enabler.
- **Cheap fast internet / bandwidth** — access remote resources smoothly.
- **Commodity hardware + large data centres** — cheap scale.
- **Web 2.0 / SOA** — services over standard web protocols.
- **Utility / grid computing** — earlier ideas of pooling + metering.

## Evolution of computing models (order)
1. **Mainframe computing** — central, dumb terminals.
2. **Personal computing** — one machine per user.
3. **Client-server** — shared server, many clients.
4. **Distributed / grid computing** — many machines work as one.
5. **Cloud computing** — resources as metered service over internet.

## Terms to know
- **Utility computing** — computing sold and billed like a utility (McCarthy's idea).
- **Grid computing** — many geographically spread computers pooled for one big task.
- **Cloud** builds on both + virtualization.
