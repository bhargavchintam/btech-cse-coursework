# Applications of Cloud Computing

Where cloud is actually used. Good for "list applications" or "real-world uses" questions.

## Common application areas
- **Storage & backup** — Google Drive, Dropbox, iCloud, AWS S3. Store + sync + backup.
- **Web + app hosting** — host websites, web apps, APIs on cloud servers (EC2, App Engine).
- **Email & collaboration (SaaS)** — Gmail, Office 365, Google Docs, Zoom.
- **Big data analytics** — process huge datasets on rented clusters (EMR, BigQuery).
- **Backup & disaster recovery (DR)** — replicate data across regions, restore fast.
- **Software development / testing** — spin up test environments on demand, CI/CD.
- **Databases (DBaaS)** — managed DBs like RDS, Cloud SQL, DynamoDB.
- **Content delivery (CDN)** — CloudFront, deliver video/images from edge near user.

## Domain-wise uses
- **E-commerce** — Amazon, Flipkart handle festival-sale traffic spikes via elasticity.
- **Streaming / media** — Netflix, Hotstar run on cloud (Netflix on AWS).
- **Education** — online classrooms, MOOCs, LMS hosted on cloud (imp in 2020, remote learning).
- **Healthcare** — store patient records, medical imaging, telemedicine.
- **Banking / finance** — fraud detection, analytics, mobile banking backends.
- **IoT** — devices send data to cloud for processing + storage.
- **AI / ML** — train models on cloud GPUs, use ML APIs (Rekognition, Vision API).
- **Gaming** — game servers, cloud gaming, matchmaking.
- **Social media** — feeds, media storage, huge scale.

## Everyday examples (relatable)
- Watching a movie on Netflix → cloud streaming.
- WhatsApp backup to Google Drive → cloud storage.
- Uploading college assignment to Google Docs → SaaS.
- Playing an online multiplayer game → cloud servers.

## Why cloud suits these
- **Variable load** → elasticity handles spikes (sales, exam results day).
- **Global users** → data centres near them.
- **Pay per use** → startups avoid heavy upfront cost.
